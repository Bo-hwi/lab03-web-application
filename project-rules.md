# Lab 03 Project Rules

- Use React 19, Vite, JavaScript, CSS and browser APIs. No unrelated frameworks or third-party UI/test libraries.
- Use `createRoot`, function components, hooks and semantic HTML. Avoid removed React APIs, class components and inline event attributes.
- Derive filtered/sorted views from source data without mutating it. Use stable IDs for React keys.
- Clean up timers, subscriptions, audio nodes, fetches and event listeners in effects.
- Treat slide snippets as unverified examples. Resolve contradictions in documented contracts and test actual behavior.
- Keep the three homework projects on independent branches. Keep each implementation, test, documentation and verification commit small and descriptive.
- Record only tests actually run. Distinguish Lighthouse scores from manual accessibility results.
- Audit at least three genuine AI/reference errors with evidence and corrections; never manufacture findings.
